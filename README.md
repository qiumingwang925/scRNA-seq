# scNexus — scRNA-seq Analysis Platform

Interactive Shiny-based platform for single-cell RNA sequencing analysis.

## Overview

This platform provides a modular interface for analyzing scRNA-seq data, covering individual-sample processing, multi-sample integration, post-annotation exploration, and cell-cell communication.

**Setup and usage instructions live in [`docs/`](docs/)** — start with the [Docker setup guide](docs/docker.md) to get the platform running, or the [RStudio setup guide](docs/shiny.md) to run the Shiny apps with a local R installation. The [workflow guides](docs/README.md) walk through each module.

## Getting Started

**Docker (recommended):** a one-command Docker Compose setup — see the [Docker setup guide](docs/docker.md).

**RStudio:** run the Shiny apps with a local R installation — see the [RStudio setup guide](docs/shiny.md).
