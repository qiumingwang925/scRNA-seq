scNexus

Interactive single-cell RNA-seq analysis platform — four modules, one container.

Module I — Individual Sample

Import → QC → PCA → Doublet removal → Cell cycle → Annotation for a single sample.

port 3839

Module II — Integration

Merge multiple samples, integrate (CCA / RPCA / Harmony / FastMNN), benchmark, annotate.

port 3840

Module III — Exploration

UMAP, violin, dot plot, heatmap, differential expression and pathway enrichment.

port 3841

Module IV — Cell-Cell Communication

CellChat and LIANA cell-cell communication inference and visualization.

port 3842
Sample data is bundled at /srv/app/test-data. Module I's file browser can open it directly; for Modules II–IV (which upload from your computer), run ./extract-test-data.sh on the host to copy it into your Downloads folder first, then upload from there.
